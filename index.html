Subscriptions & payments

Balances that stay honest.

Take full or partial payments, freeze a membership with a reason and an auto-unfreeze date, and renew before expiry. The service layer allows one live subscription per member, so duplicates never slip in.

    Roles & permissions

    The right access for every staff member.

    Token-based API authentication with Laravel Sanctum and role-based access control with Spatie Permission. Navigation and API routes are both gated, so people only see and call what their role allows.

    Audit trail

    Know who changed what, and when.

    Every create, update, delete, restore and status change is logged append-only, with before and after values per field. Sensitive values are redacted, and only Super Admin and Admin roles can read the trail.
